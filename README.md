The design authority for the CloudsForge microservice estate. Every other repository in the
programme is governed by a document in here.

Start at [`ecosystem/README.md`](ecosystem/README.md) — the programme index. The per-repository
mapping is
[`ecosystem/03-repository-responsibilities.md`](https://github.com/cloudsforge-online/micro-docs/blob/main/ecosystem/03-repository-responsibilities.md).

Links between documents inside `ecosystem/` are relative and resolve on GitHub as they stand.
Links from a *sibling* repository into this one must be absolute, because each repository is
standalone on GitHub and this one is `micro-docs`, not `docs`.
